## 2026-11-13 (Session 3)

### Added — What Counts as Homework

Defined "homework" explicitly so boys can't argue loopholes ("not due yet," "just practice"). Definition: anything you're required to do at home that's educational or practice in nature. The due date doesn't matter.

Includes: school assignments (even long-term not due yet),, instrument practice, studying for tests (when scheduled),, online school work (Google Classroom, IXL),, other required educational/practice work (left open for future).

Not homework: chores (separate floor item),, reading (after screens off, before lights out),, optional/enrichment activities.

Added to: floor-expectations (new section),, README (Key Decisions),, fridge-sheet (new callout section),, kid-presentation (fridge rules list),, day-types 01/04/05 (Before Screens references).

### Changed — Weekend Morning Screen Time (8am-10am)

Saturday, Sunday, and weekday off: boys get screens 8am-10am as free time. At 10am sharp, parent collects iPads (Phase 1) or boys self-manage transition (Phase 2). Floor items done before screens come back. They can do chores/floor items earlier than 10am if they want, but the expectation is they get moving at 10am.

Updated across all documents: Saturday and Sunday Phase 1 and Phase 2 flowcharts, floor-expectations Phase 1 sections, fridge sheet (day cards now show "Free time 8am-10am"), kid presentation script, README Phase 1 description.

### Added — Fridge Sheet (Printable)

Created `fridge-sheet.html` — a print-optimized reference sheet for the boys, designed to be taped next to the fridge. Kid-friendly language, two-column layout, checkboxes, color-coded sections. Covers: every-day rules, how iPad hand-off works now (Phase 1), December 11 preview, and day-by-day before-screens checklists for all 5 day types. Open in browser and print.

### Changed — Phase 1 Floor Check Happens When Parent Is Available

Updated school day and weekday off Phase 1 workflows to reflect reality: Denise works from home and may be in meetings when boys arrive or when floor needs checking. The iPad hand-off happens when the parent is free, not on demand. Boys wait — the wait is intentional baseline data on impulse control.

Updated across:

Parent hands over the iPad after homework/chores/spot check is done and checked. Parent collects the iPad at screens-off time. No software parental controls needed.

### Core Distinction Made Explicit Throughout

| | Phase 1 — Baseline | Phase 2 — Trial |
|---|---|---|
| Floor check | Parent pre-checks before screens | Boy self-manages, parent steers on failure |
