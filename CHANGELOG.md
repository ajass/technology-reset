# Changelog

All notable changes to the technology reset plan, tracked by date.

## 2026-11-13 (Session 2)

### Changed — Two-Phase Model Made Explicit Across All Documents

**Problem:** All day-type workflows and floor expectations showed only the Phase 2 (autonomy trial) end state. Phase 1 (baseline, parent-enforced) was mentioned in the timeline but not reflected in the workflows, rules, or diagrams. A reader could not tell when the floor was being established vs. when autonomy was being tested.

**Fix:** Restructured all documents to make the two-phase model the central organizing principle:

- **README.md** — Added "The Two Phases" as a top-level section with a comparison table. Restructured the approach section around the two phases. Timeline now annotates which phase each row belongs to.
- **floor-expectations.md** — Added "Two Phases — Read This First" section at top. Each day type now has Phase 1 and Phase 2 subsections explaining what's different. Consequences section split by phase. "What Changes" section now describes the Phase 1 → Phase 2 shift explicitly.
- **day-types/01-friday.md** — Added Phase 1 flowchart (parent checks homework, parent enforces transitions). Existing flowchart relabeled as Phase 2. Added "Two Phases" header.
- **day-types/02-saturday.md** — Added Phase 1 flowchart (parent enforces 10am, parent verifies chores). Existing flowchart relabeled as Phase 2. Added "Two Phases" header.
- **day-types/03-sunday.md** — Added Phase 1 flowchart (parent enforces 10am, parent checks spot check). Existing flowchart relabeled as Phase 2. Added "Two Phases" header.
- **day-types/04-school-day.md** — Added Phase 1 flowchart (parent checks homework). Existing flowchart relabeled as Phase 2. Added "Two Phases" header.
- **day-types/05-weekday-off.md** — Added Phase 1 flowchart (Denise verifies full floor checklist, Aaron verifies when home). Existing flowchart relabeled as Phase 2 with note that 10am transition stays parent-checked. Added "Two Phases" header.
- **kid-presentation.md** — Restructured into "Step 1: The Baseline Week" and "Step 2: The 30-Day Trial" sections. Rollback explained in terms of the two steps. Added practical note #8 about explaining rollback in two-step terms.
- **non-compliance-examples.md** — Added "Phase Context" section explaining how scoring differs between phases. All example tables now have separate Phase 1 and Phase 2 columns. Added key principle #6 about what each phase's data measures.
- **tracker-reference.md** — Added "Two Phases, One Tracker" section. Phase differences noted for Bedtime and Screen Transition categories. Daily Tracker structure updated (7-day baseline, not 21-day). Timeline table now has "What the data measures" column. Consequences table now has Phase column.

### Core Distinction Made Explicit Throughout

| | Phase 1 — Baseline | Phase 2 — Trial |
|---|---|---|
| Floor check | Parent pre-checks before screens | Boy self-manages, parent steers on failure |
| Screen access | Parent grants after floor verified | Self-granted within the floor |
| Parent role | Enforcer | Observer / steerer |
| If floor unmet | Screens stay closed until done | Redirect + log, screens resume after |
| Duration | 1 week (Nov 13-20) | 30 days (Nov 27 - Dec 27) |
